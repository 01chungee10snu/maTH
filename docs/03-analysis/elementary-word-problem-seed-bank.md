# 초등 문장제 문제 Seed Bank 확보 기록

## 목적

단계적 수학학습 앱에 넣을 초등학교 수준 문장제 문제를 확보한다. 외부 검색은 교육과정 범위, 문항 유형, 관계 사고가 필요한 영역을 확인하는 데만 사용했고, 문제 원문은 모두 새로 작성했다.

## 외부 확인 근거

- 교육부 2022 개정 교육과정 행정예고 자료에서 수학과 교육과정이 별책으로 제시되어 있음을 확인했다. 앱 범위는 초등 수학의 수와 연산, 변화와 관계, 도형과 측정, 자료와 가능성으로 제한한다.
- 2022 개정 수학과 교육과정과 초등 성취기준 연계성 연구를 확인해, 단순 계산보다 문제 해결, 추론, 의사소통, 연결 역량이 문장제 설계에 반영되어야 함을 기준으로 삼았다.
- 분수 나눗셈 문장제 연구를 확인해, 분수 나눗셈은 식 계산뿐 아니라 상황 구성, 단위량 해석, 포함/등분 구분에서 어려움이 크므로 별도 유형으로 확보했다.
- Common Core 초등-중등 전환 기준을 참고해 비, 비율, 단위율, 측정 단위 변환이 실생활 문장제의 주요 축임을 확인했다.

## 생성한 문제은행

- 파일: `data/elementary_word_problem_seed_bank.json`
- 생성기: `scripts/generate_elementary_word_problem_seed_bank.js`
- 문항 수: 1,120개
- 유형군 수: 56개
- 난이도: 1-12 전 구간
- 범위: 초등 1-2학년군, 3-4학년군, 5-6학년군
- 원칙: 외부 문항 복사 없음. 모든 문장제는 앱용 원본 seed를 deterministic template으로 생성.

## 유형군 예시

- 덧셈/뺄셈: 합치기, 변화량 미지, 결과 미지, 처음 수 미지, 비교 차이, 부분-전체
- 곱셈/나눗셈: 동수누가, 배열, 등분 나눗셈, 포함 나눗셈, 미지수 요인, 나머지 해석, 단위량
- 분수/소수: 전체-부분, 같은 분자 비교, 동치분수, 이분모 덧셈/뺄셈, 분수의 양, 분수 나눗셈
- 측정: 길이 비교, 시간 경과, 들이 변환, 무게 차이, 부피, 길이 배율 전이
- 비율/비례: 비의 언어, 단위율, 백분율, 비례 가격, 비례배분, 지도 축척, 속도 전이
- 자료/가능성: 표 합계, 표 비교, 막대그래프 비교, 평균, 미지 평균, 그림그래프 단위, 가능성 비교

## 앱 통합 시 우선순위

1. 기존 관계형 문장제 은행과 새 seed bank의 스키마를 맞춘다.
2. `curriculum_topic`, `grade_band`, `skill_tags`, `difficulty` 기준으로 라우터가 섞어 출제하게 한다.
3. 관계 사고가 중요한 단원은 새 seed bank 중 단원 정합성이 높은 문제만 우선 사용한다.
4. IRT에 바로 넣을 문제는 수동 검수 후 `irt.b`를 부여한다.
5. 정답만 기록하지 말고 오개념 코드와 힌트 사용 단계를 함께 기록한다.
